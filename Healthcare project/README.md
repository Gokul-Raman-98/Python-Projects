# Project Description
This project performs Exploratory Data Analysis (EDA) on a hospital data to uncover patterns in patient diagnosis and treatments. We use libraries like Pandas, Matplotlib, Seaborn for cleaning, visualization, and analysis.

## Objective
The goal of this project is:

1. To do basic analysis of the data (i.e, total no.of patients, distribution by gender, patient age-group).
2. Finding commonly diagnosed patients with respect to gender.
3. Duration of patient stay.
4. Identify risk factor of patients with cause of death.
5. Percentage of deceased, under-treatment and recovered patients.
6. Peak days of week for patient admissions and discharges
7. Total number of patientsadmitted and discharged per month in every year.
